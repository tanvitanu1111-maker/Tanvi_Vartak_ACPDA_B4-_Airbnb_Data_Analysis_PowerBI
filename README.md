# Airbnb Data Analysis – Power BI Capstone Project

## Project Overview

This capstone project focuses on analyzing Airbnb data using Microsoft Power BI. The project includes data cleaning, transformation, data modeling, analysis, and dashboard development to generate meaningful business insights.

## Dataset

The project uses four main tables:

- Calendar
- Hosts
- Listings
- Reviews

## Data Preparation

The data was prepared in Power Query before creating the dashboard. The preparation included reviewing the data, checking column quality, identifying errors and empty values, and applying appropriate transformations where required.

## Data Model

The tables were organized and related to support analysis across Airbnb listings, hosts, reviews, and calendar information.

## Power BI Dashboard

The Power BI dashboard presents key insights from the Airbnb dataset through interactive visualizations and analytical views.

## Key Areas of Analysis

- Airbnb listings analysis
- Host analysis
- Review analysis
- Pricing and availability analysis
- Geographic analysis
- Overall Airbnb performance

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- GitHub
